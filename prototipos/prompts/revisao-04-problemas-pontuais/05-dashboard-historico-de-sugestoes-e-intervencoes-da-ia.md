Prompt de ajuste pontual — tela **Dashboard**, problema: falta histórico de sugestões e intervenções da IA.

## O problema

O painel de detalhe de um passo da Trilha Visual (dentro do modal de detalhe do aluno) já tem, ou vai ganhar, um campo para o professor registrar uma intervenção pontual naquele passo. Mas não existe hoje nenhum lugar para visualizar o **histórico** dessas intervenções, nem o histórico de sugestões que a própria IA já fez para aquele aluno naquele ponto da jornada.

## ADICIONAR

- Dentro do mesmo painel de detalhe de um passo da Trilha Visual, abaixo do campo de nova intervenção, uma lista com o **histórico completo** de registros daquele passo: cada entrada mostrando data/hora, autor (IA ou o professor) e o texto da sugestão/intervenção.
- Se não houver nenhum registro anterior para aquele passo, mostrar um estado vazio simples (ex.: "Nenhuma intervenção registrada ainda neste passo").

## MANTER

- O campo de texto + botão "Salvar comentário" para uma nova intervenção, já especificado para este painel.
- O restante dos dados do passo (conteúdo acessado, atividade, resposta, tempo, tentativa, ordem, progresso).
