o espelho no repositório para dar contexto a quem trabalha no código.

> **Obsidian:** abra `docs/segundo-cerebro/` como vault e os links `[[...]]`
> funcionam (são relativos à raiz do vault). No GitHub eles aparecem como
> texto — use o índice abaixo.
>
> Caminhos como `/workspace/...` citados nas notas são do ambiente dos bots,
> não do repositório. Nenhuma nota contém segredo (chaves, senhas, tokens,
> connection strings).
>
> O vault **Segundo Cérebro Reuniões** (atas de reunião) é outra base e não
> entra aqui.
