# Fontes do Drive — TCC TrailUp

Cópias em Markdown dos documentos de projeto que vivem no Google Drive
([pasta de documentação](https://drive.google.com/drive/folders/1-hMe8qKLGvPTtDZ-b0HlvbSRwQhtZtug)).
Conversão automática docx → Markdown em 2026-10-18: **só texto e tabelas**;
imagens e diagramas ficaram de fora. O original no Drive é a fonte de verdade —
edite lá, não aqui.

Os capítulos consolidados do TCC continuam em [`../`](../README.md); esta pasta
guarda o material de origem.
