TrailUp

Trilhas de estudo gamificadas que se adaptam ao perfil de jogador de cada aluno. O professor monta a trilha; a IA gera o material para os sete perfis BrainHex, observa como o aluno estuda e ajusta o caminho. Esta é a documentação completa do sistema: arquitetura, modelagem, dados, IA e histórico.

Princípios de projeto

Fronteira
A API só faz IA

Fila, agenda, progresso, notificação e autorização vivem no Postgres. Se a API cair, nada que dependa de relógio para.

Duas camadas
Base por perfil + ajuste por aluno

O material pesado é gerado uma vez por turma, tópico e perfil. Cada aluno recebe só uma camada leve por cima.

Honestidade
Hipótese é hipótese

Casar formato com perfil não tem evidência de ganho de aprendizagem; o sistema oferece todos os formatos a todos e diz isso.

Privacidade
IA só para maiores

Sem data de nascimento confirmada, nenhuma chamada a modelo sai. A mídia passa por link curto e assinado.
